      How to label

      Outline: right = the app's outline follows the piece; wrong = it cuts in or spills out; not a piece = a clump, half piece or background.
      Edge codes: click an edge to cycle T (tab) → B (blank) → F (flat); then "Codes right". A red ring marks a code you changed.
      Trace and True corners (optional, in the big view): the true outline, and the 4 real corners clockwise from the one nearest the app's corner 0; saved in the read's pixels, like the app's outline. Mark edge codes by the app's edge numbers (shown small).
      Labels are kept in this browser per report until you load another; "Save labels" writes the answer key file.
